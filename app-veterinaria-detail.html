¿Qué es veteApp?

veteApp es una aplicación web desarrollada para simplificar la gestión diaria de clínicas veterinarias. Permite registrar pacientes, asignar y consultar turnos, y mantener un historial clínico actualizado de cada animal.

Motivación

El proyecto surgió de la necesidad real de una veterinaria de la zona que manejaba todo en papel. El objetivo fue digitalizarla con una solución simple, sin curva de aprendizaje y accesible desde cualquier dispositivo.

Funcionalidades

  • Registro y búsqueda de pacientes (mascotas y dueños)
  • Gestión de turnos con calendario
  • Historia clínica por paciente
  • Autenticación de usuarios con Firebase Auth
  • Base de datos en tiempo real con Firestore

Tecnologías utilizadas

  • React — UI y manejo de estado
  • Firebase Auth — autenticación
  • Firestore — base de datos en tiempo real
  • CSS Modules — estilos por componente
  • Vercel — deploy y hosting

Instalación local

git clone https://github.com/tweegio/veteApp
      cd veteApp
      npm install
      npm run dev
Necesitás configurar tus propias credenciales de Firebase en un archivo .env local.

Lo que aprendí

Fue mi primer proyecto con Firebase. Aprendí a estructurar colecciones en Firestore, manejar listeners en tiempo real y separar la lógica de autenticación del resto de la app. También mejoré mucho en el manejo de estado global con Context API.
