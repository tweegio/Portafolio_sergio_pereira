Decisiones técnicas

Multipágina por servicio para SEO

Cada servicio tiene su propia URL en lugar de estar agrupado en una sola página. Esto permite que cada servicio sea indexado de forma independiente por los buscadores, mejorando el posicionamiento para búsquedas específicas como "soporte IT zona sur" o "instalación de redes empresas".

SEO técnico desde la base

El proyecto incluye sitemap.xml para guiar a los crawlers por todas las páginas del sitio, robots.txt para control de acceso, y un archivo _headers con configuración de headers HTTP de seguridad (X-Frame-Options, X-Content-Type-Options, etc.).

Cero dependencias externas

El sitio corre con HTML, CSS y JS puros, sin frameworks ni librerías de terceros. Esto garantiza tiempos de carga mínimos, sin overhead innecesario para un sitio institucional de estas características.
