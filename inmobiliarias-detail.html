Sobre el proyecto

Portal inmobiliario estático para la zona sur del Gran Buenos Aires, desarrollado como solución escalable y sin dependencia de backend. El sitio organiza inmobiliarias y ciudades en páginas individuales, permitiendo crecer el contenido sin modificar la arquitectura base.

Arquitectura

Sitio 100% estático con páginas separadas por ciudad e inmobiliaria, deployado en Vercel con configuración personalizada vía vercel.json. Al no tener backend, el mantenimiento es mínimo y el costo de hosting es cero. 

inmobiliarias-zona-sur/

├── sitemap.xml / robots.txt
├── css/ · js/
├── ciudades/          ← una página por ciudad
└── inmobiliarias/     ← una ficha por agencia

Decisiones técnicas

SEO desde la estructura

Cada página tiene sus propios meta tags, canonical, Open Graph y Schema.org (RealEstateAgent en JSON-LD). Las URLs son descriptivas, la jerarquía de headings es correcta y se incluyeron sitemap.xml y robots.txt en la raíz para facilitar la indexación.

Seguridad sin backend

Aunque el sitio es estático, se implementaron buenas prácticas de seguridad: Content-Security-Policy vía <meta>, headers HTTP configurados en vercel.json (X-Frame-Options, X-XSS-Protection), escape de caracteres en JS con escapeHTML() y links externos con rel="noopener noreferrer".

Diseño responsive sin frameworks

Layouts construidos con CSS Grid y Flexbox. Tipografía fluida con clamp(). Menú hamburguesa en mobile implementado con JavaScript vanilla e integración de atributos ARIA para accesibilidad.

Features implementadas

Schema.org JSON-LD Open Graph sitemap.xml CSP headers X-Frame-Options escapeHTML() CSS Grid + Flexbox clamp() tipografía fluida ARIA accesibilidad

Deploy

El proyecto está configurado para deploy continuo en Vercel: cada git push a main dispara un rebuild automático. No requiere build process — Vercel sirve los archivos estáticos directamente. Soporta dominio personalizado con SSL automático.
