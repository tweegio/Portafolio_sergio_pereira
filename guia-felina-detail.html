Contexto

// producto propio · Service-Net Soluciones IT

Guía Felina es un portal de contenido sobre gatos organizado por silos temáticos (razas, salud, alimentación, cuidados, comportamiento, adopción). El objetivo fue construir un sitio de contenido a escala — 77 páginas y creciendo — con SEO técnico consistente en cada una, sin depender de un CMS ni de un backend.

Silos temáticos

Arquitectura por silos

El contenido se organiza en silos temáticos independientes (razas, salud, alimentación, cuidados, comportamiento, gatitos, gatos senior, adopción, productos, blog), cada uno con su propia página pilar, subcarpetas de contenido y su propio sitemap-<silo>.xml. Esta estructura refuerza la relevancia temática de cada sección para los buscadores y facilita escalar contenido nuevo sin reorganizar el sitio.

Herramientas interactivas

Además del contenido editorial, el sitio incluye 8 herramientas propias (comparador de razas, test de raza ideal, generador de nombres, buscador interno, entre otras), cada una implementada como un módulo JS independiente dentro de assets/js/tools/. El comparador y el test de raza ideal leen directamente de assets/data/razas.json, así que sumar una raza nueva no requiere tocar código de las herramientas.

Decisiones técnicas

Rutas absolutas desde la raíz

Todas las rutas del sitio (/assets/css/tokens.css, /razas/) son absolutas, nunca relativas. Esto permite copiar cualquier página a cualquier profundidad de carpetas nuevas sin que se rompa ningún enlace ni recurso — una decisión pensada para minimizar errores en un sitio que crece constantemente en cantidad de páginas.

Schema.org en cada página nueva

Cada página incluye bloques application/ld+json con al menos Breadcrumb y Article, validados contra validator.schema.org antes de publicar. Esto refuerza cómo Google interpreta y muestra cada contenido en resultados de búsqueda.

Política editorial explícita para contenido de salud

Todo artículo de la sección de salud incluye una nota editorial estándar ("Equipo Editorial Guía Felina — Contenido elaborado a partir de fuentes veterinarias públicas"), salvo que exista revisión de un veterinario real. La regla es explícita: nunca inventar un revisor. El mismo criterio de verificación aplica a la sección "Gatos de Artistas", donde todo dato sobre personas reales debe salir de fuentes públicas verificables.

De un build en Python a HTML plano — una decisión consciente

El sitio se construyó originalmente con un generador propio en Python para acelerar la creación de las primeras ~75 páginas de forma consistente. Más adelante se simplificó a la estructura actual, 100% manual y sin build, priorizando que cualquier persona pudiera mantener el sitio con solo un editor de texto — el resultado es funcionalmente idéntico (mismo diseño, mismo SEO, mismas herramientas), solo cambió cómo se genera el código. El trade-off asumido: el header y footer están repetidos en las 77 páginas y un cambio de navegación requiere buscar y reemplazar en todo el proyecto en lugar de editar un solo archivo — una desventaja razonable para el tamaño actual del sitio, resuelta con una checklist propia antes de dar por terminada cada página nueva.
